# 🐾 Know Your Spirit Animal (Python)

A fun terminal-based Python project that randomly assigns you a spirit animal
with sounds, chaos, and consequences 😈

## Features
- Random spirit animal selection
- Sound effects
- Interactive choices
- Evil Larry™ system
- Banana Cat appears after 11PM or after atleast 6 hours

## Requirements
- Python 3.x
- Windows (uses `winsound`)

## Run
```bash
python spirit_animal.py

Note: Uses winsound so only works on Windows
